## 1. 概述

- **定位**：国风物理炼丹肉鸽小游戏
- **一句话**：你是修仙世界的一名丹师，每一世在随机生成的元素地图上采药炼丹、穿行尖塔式关卡解谜破敌，直至筑基渡劫；失败便入轮回，带着道韵传承再修一世。
- **对标**：PotionCraft 的物理炼丹手感 × 杀戮尖塔的层结构推进 × 国风易理体系（两仪五行八卦）× 小游戏轻量化
- **平台**：抖音小游戏首发（个人主体），代码层双端适配（微信为后续版本目标，见开发文档§5.2）
- **变现**：纯激励视频广告，无内购，不依赖版号
- **MVP 成功标准**（验证优先）：次留 ≥ 30%、平均每用户 ≥ 3 世、人均激励视频观看 ≥ 4 次/日（指标定义见开发文档§7）

## 2. 设计支柱

1. **手感即灵魂**：研磨、投料、控火、搅拌的物理交互完整保留，不做进度条游戏
2. **肉鸽地图，元素寻访**：每世随机生成元素图，药材路径扫过元素即收集；丹方 = 元素组合的说明书
3. **关卡即炼丹考卷**：对手明示门槛、隐藏弱点，三条途径（正面/下毒/技法）全靠炼丹作答——无战斗过程，炼丹就是战斗
4. **流派自洽**：毒流不需修为（纯负面削门槛）、五行流修为保底（增益 buff）、正面流堆境界——三种玩家画像各得其所
5. **易上手有开关**：全图可见 + 自动化开关分层降门槛
6. **一世一杯茶**：单层约 15 分钟，适配碎片时间
7. **轮回有奔头**：道韵传承 + 多图鉴驱动"再来一世"，新世新图新关卡

## 3. 核心循环

### 3.1 单世内循环（第 1 层约 15 分钟）

```
开局抽取本世元素图 + 第1层节点图
节点图推进 → 点开对手节点看需求（明示境界/隐藏弱点）
   → 回丹房：采药/买药 → 研磨 → 投料(选路径) → 控火 → 搅拌(穿越元素) → 出丹
   → 携丹回节点图：交丹过关（三途径择一）
        ↑__________________________↓
节点清完 → BOSS 节点 = 筑基渡劫（境界练气三层 + 筑基丹）→ 成功=飞升结局
```

### 3.2 局外轮回循环

```
渡劫失败 → 道韵结算（看广告可翻倍）→ 传承商店消费道韵
    ↑                                    ↓
    └──── 带增益开启下一世（新元素图+新节点图）←── 图鉴推进/永久加成
```

### 3.3 世与层（完整规划 / MVP 裁剪）

| 层 | 对手境界 | 状态 |
|---|---|---|
| 第 1 层 | 练气境对手（8 节点+BOSS） | **MVP 实装** |
| 第 2 层 | 筑基境对手 | V1.1+ |
| 第 3 层 | 金丹境对手 | V1.2+ |

MVP 结局：第 1 层 BOSS（筑基渡劫）成功 = 飞升（"道友已飞升，仙界篇未完待续"）。飞升后可继续轮回：刷图鉴、冲极速通关。

## 4. 炼丹玩法规格（核心：肉鸽元素地图机制）

### 4.1 元素地图（丹房界面）

- **肉鸽生成**：每世开局随机生成一张元素分布图，本世所有炉共用；轮回后下一世重抽
- **元素体系（15 种，平级素材）**：两仪（阳、阴）+ 五行（木火土金水）+ 八卦（乾兑离震巽坎艮坤）；四象不入图
- **地图宏观结构**：阳半区/阴半区两大板块；生成规则由数值智能体 M3 填充，硬约束：**任何一世的地图必须保证全部丹方（含战斗丹）可达**
- **药材路径**：每味药材一条曲线（药性定向，参考 PotionCraft）
- **全图可见**：玩法是"用哪些药、什么顺序、怎么穿越"的路径规划解谜
- **丹液起点**：每炉从中宫（地图中心）出发

### 4.2 元素收集

- **扫过即收集**：丹液沿药材路径推进时，路径判定圈扫过元素节点即收集该元素
- **穿越精度 → 元素量**：正中精准穿越收集量大（约 2.0/节点），擦边扫过小（约 0.5/节点）；同种元素多节点累积

### 4.3 丹方 = 元素组合说明书

- 每张丹方定义所需元素组合（如"聚气丹 = 木×2 + 火×1"）
- 本炉收集的元素组合匹配丹方需求 → 出对应丹；无匹配 → 歪丹
- **双轨丹药**（v0.5 新增分类）：
  - **修行丹**（内服）：境界突破、渡劫、自增益——修仙主线
  - **战斗丹**（对外）：毒丹削弱对手、五行散我方 buff——关卡解谜线

### 4.4 品级机制（元素量达标定品）

- 穿越精度决定元素收集量 → 元素量是否达标定品级（下品/中品/上品/极品）
- **规则按丹药个性化**，类型枚举：
  - **总量型**：全部所需元素总量达标→下品；超出 50%→中品；超出 100%→上品；含精准穿越→极品
  - **差值型**：特定元素量的差值落在区间内（阴阳平衡类丹药）
  - 其他类型 M3 可扩展，新类型须走偏离升级流程报备
- **品级的作用**：修行丹影响效果强度；**战斗丹影响削弱/buff 数值**（上品毒丹降门槛更深）——操作精度直接转化为关卡优势

### 4.5 四大操作与地图的映射（各司其职）

| 操作 | 交互 | 职责 |
|---|---|---|
| ① 研磨 | 触屏画圈驱动研杵（物理） | **定步长**：研磨度 0–100%，研得越细路径步长越长；<60% 药性打折步长锐减，>95% 过研磨药性逸散 −10% |
| ② 投料 | 点选药材入炉 | **选路径**：投哪味药，丹液即沿该药路径走一段；多味药路径首尾相接形成组合路线 |
| ③ 控火 | 文火/武火切换 + 火候条定格 | **定速度**：武火推进快但穿越判定圈缩小（易擦边漏收），文火稳判定圈大但慢；火候条定格适宜区间额外增大判定圈 |
| ④ 搅拌 | 画圈搅拌（物理） | **管推进**：沿当前药材路径继续推进穿越元素；画圈转速均匀、方向一致 → 穿越精准 |

### 4.6 歪丹机制

- 元素组合不匹配任何丹方 → **哑丹**（无效果可卖钱）
- 炸炉 → **糊底丹**（残留物，可卖）
- 歪丹进图鉴；怪味丹延后 V1.1+

### 4.7 炉内丹毒

- 每次投料累积（常 +2 / 中 +4 / 稀有 +8），是炸炉风险主因子——"少药精准"vs"多药暴力"的权衡
- 反向搅拌可减（−5，代价推进效率 −5%）

### 4.8 元素地图 UI

- 元素节点（15 种，视觉家族化：两仪圆形、五行五色、八卦卦符）、药材路径、丹液点实时呈现
- 双指缩放；本炉已收集元素栏 + 炸炉风险条常驻；丹方需求进度条常驻顶部

### 4.9 自动化开关

| 开关 | 效果 | 代价 |
|---|---|---|
| 自动研磨 | 跳过研磨，研磨度固定 80% | 步长锁定中档 |
| 自动搅拌 | 搅拌自动完成（匀速推进） | 穿越精度下降约一档品级 |

- 默认关闭，第 3 次炼丹后提示；选药、投料顺序、控火仍需玩家决策

### 4.10 相生相克与六十四卦配合（V1.1+，MVP 不做）

预留：收集顺序生克链、八卦两两同收 64 卦象效果。**红线重申**：丹方是 15 种平级元素的组合说明书，药材是具体药材，任何版本不得改回"五行组合语法"。

### 4.11 物理实现锚点

- 研杵、药材、丹丸：Box2D 刚体；搅拌画圈手势 → 角速度采样驱动推进
- 丹液、火焰、烟雾：参数化伪物理（粒子+曲线动画）
- 元素地图逻辑：纯数据驱动（种子生成、可达性校验、路径插值、穿越判定、元素量结算），单测友好
- 指跟手延迟 < 50ms 感知标准（M2 验收项）

## 5. 层结构与对手系统（关卡核心，v0.5 新增）

### 5.1 节点图（层界面）

- **结构**：类杀戮尖塔节点路线图——起点 → 分岔路径 → 汇聚 → 层末 BOSS；单向推进，当前节点可反复尝试挑战（防死锁：境界/丹药不足时可先去草药园/丹房补强再回来）
- **MVP 第 1 层规模**：8 节点 + BOSS（小怪×4 + 精英×1 + 草药园×2 + 问号×1 + BOSS）
- **随机性**：节点图与元素图同节奏，每世随机生成（拓扑、对手排布、事件内容均随机；对手类型配比保证）
- **双界面切换**：节点图（推关卡、看对手需求、交丹过关）⇄ 丹房（元素地图炼丹）——两张界面即游戏的两个半球

### 5.2 节点类型

| 类型 | 功能 | MVP 数量 |
|---|---|---|
| 小怪 | 练气境对手，三途径解谜（见 5.3），过关得灵石/药材 | 4 |
| 精英 | 强化版对手（门槛更高、隐藏属性更强），过关得稀有药材/丹方残页 | 1 |
| 草药园 | 采药节点：免费获得随机药材（品级随机） | 2 |
| 问号 | 随机事件节点（**具体事件类型待定**：奇遇/灵石/小挫折等，M2 原型期定） | 1 |
| BOSS | 筑基渡劫（见 5.4） | 1 |

### 5.3 对手解谜（无战斗过程，v0.5 核心创新）

**信息展示规则**：
- **明示**：正面对战所需的境界门槛（如"练气二层"）
- **隐藏**：毒抗、五行属性的具体数值（玩家知道"下毒有效果，但效果多少不知道"）

**三条过关途径**：

| 途径 | 机制 | 流派画像 |
|---|---|---|
| **正面对战** | 境界 ≥ 明示门槛即胜——靠炼修行丹冲境界 | 稳健正面流：修为是硬实力 |
| **旁门左道（毒）** | 毒丹**降低**该对手的境界门槛；门槛降到练气一层（地板）= 等价毒杀过关。实际效果受隐藏毒抗折减 | 纯负面流：不需修为，专注炼毒 |
| **属性技法（五行散）** | 服用后**我方**正面对战判定时境界临时 +N 层（buff），需自身修为作保底（保底数值 M3 定）——一层+buff 够不着三层门槛，防止无修为纯 buff 逃课 | 五行增益流：修为+buff 双修 |

**解谜性**：对手明示门槛，但毒抗/五行属性隐藏——玩家决策"这个对手走哪条线成本最低"：正面要炼几炉聚气丹？下毒赌毒抗？五行散配合现有境界？不同对手 + 每世随机元素图 = 每世的最优路线都不同。

**数值框架**（数值智能体 M3 填充）：
- 小怪：门槛练气一层~二层；毒抗/五行属性低~中
- 精英：门槛练气二层~三层；毒抗较高（毒杀成本高）
- BOSS（渡劫）：不适用常规三途径（见 5.4）

### 5.4 BOSS 节点 = 筑基渡劫

- **入场券**：境界练气三层 + 筑基丹×1（明示）
- **玩法**：保留原渡劫设计——三段控火 QTE；清心丹可减失败惩罚
- 毒/五行散对渡劫无效（天雷无弱点）——设计意图：渡劫是修仙本命的仪式感，战斗丹是人与人斗的邪路；玄水符丹是唯一例外（QTE 判定圈扩大，属"借势"而非"克敌"）
- **失败**：渡劫失败 → 轮回（道韵结算）；复活广告点位在此触发（每世 2 次）
- **成功**：飞升结局 = MVP 通关

### 5.5 与炼丹系统的经济咬合

- 每次炼丹消耗**炼丹体力**（回春丹/问号节点恢复）——节奏控制器
- 战斗丹是一次性消耗品（用过即逝），修行丹部分永久（境界突破）部分一次性（buff 类）
- 对手过关奖励（灵石/药材/丹方残页）反哺炼丹经济——两半球循环咬合

### 6.4 境界

### 6.5 道韵传承商店 ×6

### 6.6 图鉴

药材 10 格 + 丹药 14 格（12 正丹 + 2 歪丹）+ 元素 15 格 + **对手 6 格**（击败后点亮并展示其隐藏属性——"复盘"乐趣）。图鉴完成度是道韵结算因子。

### 6.7 平衡目标（数值智能体约束）
