# 丹道轮回 · 项目长期记忆

## 项目定位
- 国风物理炼丹肉鸽小游戏，对标 PotionCraft，个人主体，抖音小游戏首发（代码双端适配，微信因个人主体门槛列为 V1.2+）
- 变现：纯激励视频广告 ×4 点位，无内购无版号依赖

## 已冻结的关键决策（2026-10-22 面试）
1. 物理手感完整保留 + 自动化开关（自动研磨/搅拌，各 −5% 融合度上限）分层降门槛
2. 肉鸽轮回制：练气→筑基渡劫，败则轮回，道韵传承+双图鉴驱动
3. 极小验证版 MVP：药材10/丹方8/2境界/单世15分钟，验证优先（用户在了解三档差别后主动选择，已知留存数据会失真，用三世率交叉判断）
4. Cocos Creator 3.8 LTS + TS；无后端（本地存档）；Box2D+伪物理混合
5. 防作弊接受风险；AI 生图主导美术（水墨淡彩国风）
6. 五里程碑闸门：M1规格冻结→M2可玩原型→M3内容量产→M4真机集成→M5提审终审，闸门间自主+规格偏离升级
7. 炼丹核心机制（v0.4 定稿）：肉鸽元素地图——每世随机生成元素图（世内共用，轮回重抽）+ 两仪2/五行5/八卦8共15种元素平级入图（四象裁剪）+ 药材路径扫过元素即收集 + 丹方=元素组合说明书 + 穿越精度→元素量→品级（规则按丹药个性化：总量型/差值型）+ 四操作各司其职（研磨定步长/投料选路径/控火定速度与判定圈/搅拌管推进）+ 只保留炉内丹毒；相生相克/64卦配合、怪味丹延后V1.1+。**红线：丹=具体药材的组合**（用户底线，禁止"丹方=五行组合"语法）；地图生成器可达性校验（8丹方全可达）是工程硬约束
- 对标参考：PotionCraft（药材路径曲线、物理手感）、《不问凡尘》（丹毒机制）

8. 层结构与对手系统（v0.5 定稿）：类杀戮尖塔节点图（一世3层，MVP第1层8节点+BOSS，每世随机生成）+ 对手无战斗解谜制（明示境界门槛/隐藏毒抗五行属性）+ 三途径（正面=境界达标；毒=降门槛至练气一层地板=毒杀，纯负面流；五行散=我方buff修为保底，增益流）+ 节点图与丹房双界面 + BOSS=筑基渡劫（毒/散无效，玄水符丹唯一例外）；丹方12张=修行丹8+战斗丹4；对手6个；三流派全通关模拟+12丹方全可达=M3数值硬约束
